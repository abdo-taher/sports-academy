# Stage and Level Progression Model

## Canonical Hierarchy

`Sport → Program (where applicable) → Stage → Level`

Stage and Level are not synonyms. A Stage is a broader ordered progression phase; a Level is the finer Student progression unit. Every Level belongs to exactly one Stage and one Sport/Program context. The number, names and order of Stages and Levels are approved configuration, never universal constants.

## Level Definition

Each Level has ordering, Stage ownership, Sport/Program context, active/inactive state, effective-dated Evaluation criteria and progression requirements. Criteria changes create a new approved version and never reinterpret an earlier Evaluation.

## Student Progression

The Student's current Stage is derived from the current approved Level. A Level Evaluation can produce remain, progress, re-evaluate or approved movement/demotion. Completing the final Level may move the Student to the first eligible Level of the next Stage after human approval. Program transfer revalidates the destination Program's Stage/Level structure; it never maps silently.

## Required History

Preserve previous/new Program, Stage and Level, Evaluation and criteria version, system and human recommendations, final decision, approver, reason, effective date and any authorized exception.
