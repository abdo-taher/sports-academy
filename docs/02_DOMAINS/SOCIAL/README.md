# Social and Survey Domain

## Scope

CURRENT. This domain owns interactive feed content and structured response collection.

This is an Academy-owned permissioned feed/Survey capability. It does not activate the public marketplace/community modules that remain Future under BD-027.

## Canonical Distinctions

- **Communication/Notification** delivers operational business events/messages.
- **Post** is audience-scoped feed content supporting reactions/comments.
- **Survey** is structured response collection containing Questions.
- None is a generic Message substitute.
