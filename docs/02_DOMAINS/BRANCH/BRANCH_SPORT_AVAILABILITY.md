# Branch Sport Availability

## Approved Business Truth

`APPROVED BUSINESS TRUTH — BD-002 / BR-BRA-001`

A Sport must not be shown as available in a Branch unless that Branch supports or enables that Sport.

## Applies To

- Registration
- Trial booking
- Program/Service selection
- Training Group creation
- Scheduling
- Subscription creation
- Frontend filtering
- API validation
- QA scenarios

## Prohibited Behavior

- Showing unsupported Sports for a Branch.
- Allowing Subscription creation for a Branch/Sport combination the Branch does not support.
- Treating BD-028 as reopening this rule.
