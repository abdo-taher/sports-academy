# Subscription Renewal

Approved model:

- BR-SUB-007 — Renewal creates a new linked Subscription and preserves the old commercial period and history.
- BR-SUB-010 — Carry-over occurs only by Plan policy, with provenance in the new Ledger and no automatic cross-Sport transfer.
- BR-SUB-011 — Overlap is allowed only when Attendance funding is deterministic; balances never merge.

Early/on-time/late windows and carry-over limits are configuration.
