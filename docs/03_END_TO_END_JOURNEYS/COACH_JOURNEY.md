# Coach Journey

## End-to-End Flow

| Stage | Preconditions / Rule | Approved Behavior | Blocked or Exceptional Behavior | History / Communication |
|---|---|---|---|---|
| Assignment | Branch offers Sport/Program; qualification and conflicts checked | Multiple approved effective-dated Branch/Sport assignments allowed. | BR-COA-001 and process authority matrix. | Assignment start/change history retained. |
| Schedule | Recurring Group Schedule and calendar valid | Coach works only within active assignment. | Conflict blocks until authorized resolution. | Effective schedule history retained. |
| Replacement | Specific Session needs Substitute | Substitute covers only that Session and never becomes Primary automatically. | Extended absence uses future reassignment; cancellation uses BR-SES-001/002. | Session assignment/reason retained. |
| Attendance support | Coach assigned and process permission configured | Only allowed recording action is available. | Correction requires process approval. | Attendance owns official/correction history. |
| Evaluation | Official Evaluation type/model exists | Coach records; Supervisor/authorized Admin approves/publishes. | Movement uses configured Sport/Level criteria. | Versions and approval history retained. |
| Session report | Coach is assigned | BR-REP-001 permits an assigned Coach to write a Session report. | Parent/admin comments cannot erase it under BR-REP-003. | Report and comments remain distinct, auditable records. |
| Suspension / Exit | Authorized actor initiates effective-dated change | Future responsibilities are reassigned. | Historical Groups/Sessions/Evaluations never rewritten. | Preserve decision/assignment history. |

## Journey Completeness

`BUSINESS READY WITH CONFIGURATION REQUIRED`. Coach absence never silently cancels, reassigns or compensates a Session.
