# Evaluation Journey

## End-to-End Flow

| Stage | Preconditions / Validation | Approved Behavior | Open / Rejected Behavior | History and Hand-off |
|---|---|---|---|---|
| Select type/template | Student, Sport and purpose identified | Use versioned Sport-specific model under BR-EVA-001. | Configured criteria/template authority. | Template/version retained. |
| Initial Evaluation | Applicable policy and assigned Coach exist | Level recommendation requires Evaluation where policy requires. | Optional Trial policy is resolved before evaluation. | Assessment/version retained. |
| Periodic Evaluation | Authorized schedule/configuration invokes assessment | Scheduling may be configured by authorized administration under BR-EVA-002. | Exact frequency/scope and configuration authority remain governed; no generated interval. | Retain occurrence and template version. |
| Review / Approval | Coach submits completed assessment | Supervisor/authorized Admin approves or rejects. | Creator cannot bypass reviewer. | Decision/reason retained. |
| Publication | Approved Evaluation exists | Authorized publisher exposes official version. | Parent cannot edit under BR-PAR-003. | Publication event retained. |
| Promotion / Demotion / Placement | Approved Evaluation and configured Sport/Level criteria | Authorized role makes final governed decision; typed Transfer applies when the governed movement requires it. | Override/rejection keeps original recommendation/reason. | Old/new Level, effective date and history. |
| Correction | Error found | Create new version and repeat approval. | Original never overwritten. | Version link, changed fields, actor/reason/time. |

## Exception Boundary

An Evaluation recommendation is not itself a Promotion. A correction is not deletion. A Parent comment is not an official Evaluation update. Wrong placement uses configured re-evaluation/movement governance.

## Journey Completeness

`BUSINESS READY WITH CONFIGURATION REQUIRED`.
