# Final Closure Business Journeys

## Academy or Branch Operational Change

Authorized request → effective dependency inventory → owning-domain review → explicit disposition for every active relationship/Session → approvals → effective transition → scoped communication → preserved history/reporting.

Governed by BR-ACA-002, BR-SES-003, BR-BRA-004 and the Process Authority Matrix.

## Social Post

Authorized Academy Admin or scoped Coach → Draft → audience validation → Published → visible-user reaction/comment → optional author edit → authorized moderation/hide → Archive. Every edit/moderation action retains author, audience, reason and version.

Governed by BR-SOC-001/002.

## Survey

Authorized creator → Draft Survey/questions/policies → audience validation → Published/Open → governed responses → effective closure → result visibility → Archive. Late or unauthorized responses reject and anonymity is never inferred.

Governed by BR-SRV-001/002.

## Initial Placement

Applicable placement policy → authorized Coach or Admin/Evaluator assessment → configured calculation/advisory recommendation → human evaluator recommendation → Supervisor/authorized approver decision → effective Level assignment → publication to authorized audience → versioned correction if needed.

Governed by BR-EVA-003/004/009 and BR-LVL-001/002.

## Level and Stage Progression

Current Program/Stage/Level → effective Level criteria version → Evaluation → system advisory output → evaluator recommendation → human review/approval → remain/progress/re-evaluate/approved movement → first eligible next-Stage Level where final current-Stage Level is completed → history/reporting.

Pending Transfer or Archive triggers eligibility/state revalidation before execution. Governed by BR-LVL-001–003.

## Session Feedback

Authorized Coach/Admin records Session feedback → explicit Internal or Shared visibility → authorized append-only comments → optional moderation → versioned correction of official Evaluation only through its separate approval lifecycle.

Governed by BR-EVA-007/008; feedback/comments never change the Official Evaluation or Level.
