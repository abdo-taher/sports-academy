# Governance — Active Navigation

This folder tells humans and AI **what to trust, where to look, and what not to infer**. It does not replace canonical domain truth.

## Mandatory entry points

- `SOURCE_OF_TRUTH.md` — authority and conflict resolution.
- `DOCUMENT_AUTHORITY.md` — allowed use of each document class.
- `AI_START_HERE.md` — mandatory cold-start router for AI tools.
- `AI_RULES.md` — AI answer/anti-inference contract.
- `BUSINESS_QUESTION_ROUTER.md` — natural-language and cross-domain routing.
- `BUSINESS_CONCEPT_INDEX.md` — concept-to-owner lookup.
- `BUSINESS_CONCEPT_OWNERSHIP_MATRIX.md` — canonical ownership and dependencies.
- `BUSINESS_RULE_INDEX.md` — all 114 Rule IDs and canonical owners.
- `BUSINESS_GLOSSARY.md` — canonical business terminology and aliases.
- `AI_SOURCE_MANIFEST.md` — machine-friendly source routing metadata.
- `BUSINESS_COVERAGE_CERTIFICATION_MATRIX.md` — final capability/cross-domain coverage boundary.
- `AI_BUSINESS_KNOWLEDGE_CERTIFICATION.md` — current certification status.
- `DOMAIN_READINESS_MATRIX.md` — current domain readiness.
- `IMPLEMENTATION_BLOCKERS.md` — configuration/design/technical work that remains without reopening Business.
- `MINIMUM_AI_BUSINESS_SOURCE_PACK.md` — 12-file AI orientation pack.
- `TECH_STACK_LOCK.md` — canonical approved technology set and unresolved technical gates.
- `ARCHITECTURE_RULES.md` — fixed repository, Frontend, Backend and package structures.
- `DEPENDENCY_RULES.md` — dependency admission, pinning, duplication and update rules.
- `CODING_STANDARDS.md` — implementation, naming, boundary and cross-cutting standards.
- `TESTING_STRATEGY.md` — canonical test tools, placement and coverage gates.
- `NESTJS_ENGINEERING_RULES.md` — deterministic Backend module/layer boundaries and conventions.
- `VALIDATION_GOVERNANCE.md` — shared Core/CLI/MCP/CI enforcement, result contract and Business Gate.
- `TECH_DECISION_PROTOCOL.md` — required ADR route for changes to the technical lock.

Historical audits and superseded certifications are intentionally kept outside the active package.
