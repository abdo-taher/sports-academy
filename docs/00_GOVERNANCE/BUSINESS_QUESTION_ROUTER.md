## Natural-Language Cross-Domain Routes

| Example intent | Required canonical route | Stop/answer condition |
|---|---|---|
| Can this Student train/attend today? | Student state → Branch state/availability → Group/Session → Subscription eligibility/Freeze/expiry/balance → Attendance funding | Answer only after exactly one eligible funding Subscription is resolved; runtime data may still be required. |
| Can this Student move to another Branch? | Typed Transfer → destination Branch Sport/Program availability → capacity → Subscription effects → authority → communication | Apply CFG-TRN-004; stop if destination eligibility is missing or ambiguous. |
| Can a Parent change an Evaluation? | Parent relationship/visibility → Evaluation version/approval → process authority | No: BR-PAR-003; official correction follows Evaluation authority. |
| What happens when a Branch temporarily closes? | Branch lifecycle → Schedule/Session → Attendance/Subscription → Communication | BR-SES-003 requires a recorded cancel, reschedule, eligible transfer or approved exception for every future Session. |
| What happens if a Branch disables a Sport or Program already in use? | Branch availability → Program/Sport → active Groups/Sessions/Subscriptions → effective-date/history | BR-BRA-004 blocks new use and grandfathers existing approved relationships through completion/renewal. |
| Which Subscription funds Attendance when several are active? | Session context → Group membership → Subscription overlap policy → Attendance/Ledger | Exactly one eligible Subscription; ambiguity blocks under BR-SUB-011. |
| What happens when Freeze ends during Branch closure? | Freeze/Resume → Branch state → Subscription eligibility → Attendance | Subscription resumes at its approved end, while closed Branch still blocks normal operation; other gates remain independent. |
| What happens to debt when a Student is archived/returns? | Student Archive/Return → Payment/receivable history → Subscription/Group/account review | Debt/history remains; no relationship reactivates automatically. |
| What if a Guardian relationship changes during a pending approval? | Guardian relationship → owning approval process → authority/history | BR-PAR-009 revalidates at decision/execution and holds the request for authorized continuation/cancellation. |
| What are exact limits, amounts, durations or role bindings? | Owning Rule → Policy Configuration Catalog → authority matrix | Return `BUSINESS CONFIGURATION REQUIRED` if the mandatory effective value is absent. |
