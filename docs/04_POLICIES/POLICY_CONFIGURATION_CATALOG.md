# Policy and Configuration Catalog

## Governance

BD-028 and BR-CFG-001 govern every item. Resolution order is `Academy Default → approved more-specific override`. A missing override uses the Academy default. Only items explicitly marked overrideable may vary. All changes are effective-dated and audited; numeric values below are intentionally not invented.

## Non-Configurable Invariants

The canonical baseline, identity uniqueness, history preservation, non-destructive Archive, creator/reviewer separation, no normal Attendance after expiry, nonnegative Session balance, one Attendance funding exactly one Subscription, explicit Branch Sport/Program availability, purchased Plan-version pinning, audience isolation, append-only Evaluation comments, human final Level decision and the fact that Renewal creates a new linked Subscription are not overrideable configuration.
