# Change Management — Active Sources

This clean package keeps only change-management material that is still operationally useful.

## Active files

- `DECISION_LOG.md` — authoritative approved Business Decisions.
- `SOURCE_REGISTRY.md` — provenance/source registration.
- `TECHNICAL_OPEN_QUESTIONS.md` — unresolved technical/delivery questions only; these are not Business gaps.
- `TECHNICAL_DECISION_LOG.md` — technical baseline and `TECH-ADR` index; it cannot change Business behavior.
- `TECHNICAL_ADRS/` — permanent full technical decision records.
- `VERSION_HISTORY.md` — documentation/repository version history.

Historical workshops, Decision Packs, NBCG packs, old gap registers and closed-question working files are retained in the separate historical archive and are not part of the active AI/team reading path.
